# NewsHub (MERN)
One platform for many newspapers. Click a card to open the original site, save notes (CRUD), and see 4 key points per story.

## Run
1. Start MongoDB locally (or set MONGO_URI to an Atlas URL).
2. Server:  cd server && npm install && npm start      (http://localhost:5000)
3. Client:  cd client && npm install && npm run dev    (http://localhost:5173)
